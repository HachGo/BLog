# AI 工业革命学习资料库与路线图

学习目标：理解技术革命如何改变生产方式，并逐步形成对 AI 技术进步、产业扩散与商业机会的独立判断。

本资料库根据收集的学习清单整理，合并重复访谈，去除追踪参数、下载广告和无关图片。学习状态均从「待学习」开始；各页的学习重点是阅读问题，不代表已经完成研读或得出结论。

## 四周学习计划

按周完成下面的成果后勾选；整本书与长论文可先读目录、导论和相关章节，再安排深入阅读。

### 第 1 周：认识工业革命

- [ ] 从[工业革命与技术发展史](./03_历史与社会/工业革命与技术发展史)观看 Crash Course 和 BBC 纪录片。
- [ ] 阅读《技术陷阱》，结合 Robert Allen 的书整理工业革命发生的条件。
- [ ] 输出一页笔记：技术、能源、劳动与工厂制度之间有什么关系？

完成标准：能解释至少一种关于工业革命起因的观点，并记录其证据及可能的反例。

### 第 2 周：研究金融与产业周期

- [ ] 阅读[技术革命、资本与生产率](./02_产品与商业/技术革命资本与生产率)中的 Perez、《权力与进步》和生产率 J 曲线论文。
- [ ] 观看《镀金时代》，记录产业发展与财富分配的问题。
- [ ] 制作对照表：技术投资、金融泡沫、组织改造与生产率分别如何变化？

完成标准：说明资本周期与生产率变化各自解释什么，列出应用到 AI 时仍需验证的条件。

### 第 3 周：研究计算机与 AI 能力

- [ ] 阅读《第二次机器革命》，观看计算机历史纪录片。
- [ ] 从[AI 能力与产业数据](../02_Agent研究/AI能力与产业数据)阅读 AI Index，并查看 Epoch、METR 的指标说明。
- [ ] 各选一个技术能力指标和产业采用指标，记录来源、时间、定义及局限。

完成标准：区分模型能力、Agent 任务成功率、企业采用与经济收益，避免用一个指标替代其他指标。

### 第 4 周：形成自己的 AI 革命判断

- [ ] 从[Anthropic 公司研究](./02_产品与商业/Anthropic公司与AI革命研究)阅读两篇创始人文章、招股书、Economic Index 与访谈。
- [ ] 结合 NBER 论文、IEA、《AI 蛇油》及 AI 纪录片，查找支持与挑战企业观点的材料。
- [ ] 写一份判断笔记：技术进展、商业化、资本投入与产品机会分别有哪些证据？

完成标准：结论附来源与数据时间，写清不确定性、反对证据和下一步需要观察的变化。

## 六个长期研究主题

| 主题 | 持续追问 | 主要资料入口 |
|------|----------|--------------|
| 技术进步 | 模型、Agent 与 AI 自动研究的能力如何变化？可靠性是否提高？ | AI 能力与产业数据 |
| 产业扩散 | 企业是否改变实际流程？采用有哪些障碍？ | Anthropic 经济研究、技术史 |
| 经济增长 | 节省的任务时间如何转化为生产率、成本与利润变化？ | NBER、生产率 J 曲线 |
| 资本周期 | 投入与需求是否匹配？哪些预期仍待兑现？ | Perez、公司披露 |
| 社会与劳动 | 哪些任务、技能与关系发生变化？收益如何分配？ | 技术史、《权力与进步》、Economic Index |
| 创业机会 | 什么需求已可解决？谁付费？交付和验证成本是多少？ | 产品与商业、公司案例 |
