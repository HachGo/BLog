# Agent 研究

> 单独梳理编码智能体与 Agent Harness：官方仓库、定位与后续笔记入口。

## 终端编码 Agent

- [OpenAI Codex](https://github.com/openai/codex) — OpenAI 的终端编码代理，支持多平台安装与 IDE 插件生态
- [Claude Code](https://github.com/anthropics/claude-code) — Anthropic 的智能体编码工具，覆盖自然语言命令、Git 工作流与代码库理解
- [Grok Build](https://github.com/xai-org/grok-build) — xAI 的终端编码 Agent（`grok`），提供全屏 TUI、无头模式与 ACP 集成

## 开源 Harness / 教程

- [DeepSeek Harness（dsh）](https://github.com/deepseek-ai/deepseek-harness) — DeepSeek 开源的 Agent Harness，一切皆插件（Cordis），可用 `npx @deepseek-ai/dsh web` 启动
- [hello-generic-agent](https://github.com/datawhalechina/hello-generic-agent) — Datawhale Generic Agent（GA）入门教程，覆盖安装配置、浏览器自动化、记忆与自我进化
